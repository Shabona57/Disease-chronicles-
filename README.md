# Disease Chronicles

**Live site:** https://shabona57.github.io/Disease-chronicles-/

An archive of human illness — the history, causes, and evolving understanding of diseases, told one case file at a time. Built as an independent research and writing project, in Uzbek and English.

## Loyiha haqida

Disease Chronicles — kasalliklarning tarixi, kelib chiqish sabablari va zamonaviy tibbiyot ularni qanday tushunishini o'rganuvchi mustaqil tadqiqot loyihasi. Har bir kasallik "ish fayli" (case file) sifatida taqdim etiladi: qachon birinchi marta kashf etilgan, tarix davomida tushuncha qanday o'zgargan, va bugungi kunda unga qanday munosabatda bo'linadi.

Sayt ikki tilda ishlaydi — o'zbek va ingliz.

## Texnologiyalar

- Sof HTML, CSS va JavaScript (hech qanday framework yoki build vositasi kerak emas)
- Barcha kasallik ma'lumotlari `diseases-data.js` faylida massiv (array) sifatida saqlanadi
- `app.js` shu massivni o'qib, kartochkalar va to'liq sahifalarni avtomatik yasaydi
